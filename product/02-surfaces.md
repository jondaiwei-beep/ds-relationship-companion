# 02 · 界面

四个 tab + 右上角设置。s 和 D 看同一个 tab、不同内容。两人在文案里互称各自设定的称呼（`Dynamic.honorific_for_d / _for_s`），没设就用名字。

## Tab 1 · 今天 —— 每天来

### s 看到
- **头部**：日期、今天从几点算（`day_start`）、分余额、连续天数；D 是否在线/暂停中
- **问安**：早/晚一句（`Task.kind=checkin`，可一天多次），发出即回执
- **今日清单**，按顺序：D 今天加的 → 有截止的 → 循环项 → 自愿加分项（`kind=open`，无截止，单独一节「想做就做」）
  - 每条：勾 / 拍照 / 写一句 → 变成 `delivered`，立刻显示「已送到 · 等 {D} 看」；D 看过后变「{D} 看到了 · 12:40」/「{D}：很好」
  - 长按/展开：**做不了** / **求个新时间** / **想谈谈** / **我认，晚了**（都可附一句原因）
  - 被暂停的条目灰显「{D} 不在，先停」
- **今天从 D 那里来的**：D 的处置、留言、加分（时间线）
- **空态**：「今天没有要求你什么。」+ 问安入口

### D 看到
- **等我处置的**：s 的交付 + s 的四种"没做"说明，一列。每条两下：**看到了 / 很好 / 算了 / 补上 / 罚**（见 `03-domain.md` D 处置）。永不过期、不计时、无红色倒计时
- **今天 s 的概况**：3/5 已交付，1 条说做不了
- **快速加一条**：给今天（一次性）或建成循环项
- **我要记得的**：D 自己的备忘（`DNote`，带可选提醒，s 看不到）
- **今晚要什么？**：一键抽一张灵感卡（`04-explore.md`），可直接加到今天
- **空态**：「没有等你的。」

### 从这里出去的
- widget / 锁屏：s 的今日清单（前 3 条 + 完成数）；D 的「等我处置 N 条」
- 通知：见文末

## Tab 2 · 规矩 —— 长期的东西，有事才来

- **常设规矩**（`Rule`）：称呼、跪迎、禁慾、着装、汇报方式……分组显示；D 增删改，s 只读 + 可「想谈谈」
- **循环任务定义**（`Task` 列表）：每天/每周几/一天多次；每条的证明方式、分、是否需要 D 在场；D 可**按条暂停**（附恢复日期可选）
- **奖励目录**（`Reward`）：D 定，写明多少分 / 或「D 决定」；s 在「分」tab 兑换
- **惩罚库**（`ConsequenceTemplate`）：D 定；只在处置里由 D 手动触发，这里不能"执行"
- **底线与安全词**：= 探索比对里双方标「不要」的项 + 自定义；安全词永远在设置里也能看到
- **探索入口**：「两人比对」「灵感」「起步包」（`04-explore.md`）
- s 可在这里**提议**一条任务/规矩（`proposed`），D 接受后生效

## Tab 3 · 记录 —— 回头看，晚上当面收尾

- **日历**（月视图，一天一格）：格子里显示 交付数/应做数、有没有未处置、有没有留言
- **这一天**（点开一格）：按时间线——问安、每条任务的交付与 D 处置、s 的说明、D 的留言、罚、加分、兑换；**两人都可在这一天上留言**（`DayComment`，求饶/处罚/一句话）
- **交付归档**：照片/文字按天可翻
- **私人备注**：每人每天一条，只自己看（`PrivateNote`）
- **曲线**：`kind=measure` 的任务（体重、饮水）自动出折线（v1.x）
- **周 / 月**：只陈述事实（做了 N、说明 M、D 处置 K），不评价、不建议

## Tab 4 · 分 —— 余额与兑换

- 余额、可兑换奖励（够的亮、不够的显示还差多少）、**兑换申请**（s 发 → D 同意/拒绝 → 完成）
- D：**给 / 扣 / 自由加分**，附一句为什么（进流水）
- 流水：谁、多少、为什么、关联哪条
- 规则可见：哪些任务给分、哪些只有没做才扣（默认基础项 0 分）
- 连续天数（`streak`：今日应做全部交付则 +1；D「算了」不算断）和在一起的天数（只涨）

## 右上角 · 设置

设备锁（PIN/生物）、通知（内容中性开关：锁屏只显示「1 条新消息」）、伴侣与角色、称呼、一天从几点开始、时区、付费、暂停整个动态、导出、离开。

## 通知

| 事件 | 收到的人 | 默认 |
|---|---|---|
| 任务提醒（每条可设时间；日终提醒） | s | 开 |
| s 交付 | D | 开，可改为每 N 小时合并一次 |
| s 说做不了 / 求新时间 / 想谈谈 / 认晚 | D | 开，即时 |
| D 处置（看到/很好/算了/补上/罚） | s | 开 |
| D 留言、加分、奖励同意 | s | 开 |
| 兑换申请 | D | 开 |
| 问安 | 对方 | 开 |
| DNote 提醒 | D | 按条 |

锁屏内容中性开关打开时，所有通知正文替换为「{App} · 1 条新消息」。

## 首日路线

设锁 → 选角色（D / s）与称呼 → 邀请对方（链接/码；对方可以晚几天，单人先能建任务给自己）→ 挑一个起步包，逐条改成自己的话 → 「今天」出现前 3 条 → 当晚在「记录·这一天」第一次收尾。
