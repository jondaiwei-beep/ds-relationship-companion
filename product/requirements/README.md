# Product requirements

This directory stores atomic, testable product requirements migrated from Notion and reconciled with the approved product direction.

## ID format

Use `REQ-{DOMAIN}-{NNN}`, for example `REQ-TODAY-001` or `REQ-CONSENT-004`. IDs are permanent; change meaning through version history or a recorded decision, never by silently reusing an ID.

Each requirement must define purpose, actors, preconditions, behavior, edge/recovery states, permissions/privacy rules, acceptance criteria, release tier, and approval status. It must not prescribe visual layout.

Until migration and reconciliation are complete, Screen Packages must use `TBD — pending Notion migration` and stay blocked.
