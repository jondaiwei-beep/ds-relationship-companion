# Visual reference formats

- `webp/v1/`: full-resolution 853 × 1844 high-quality repository references for Codex, Claude Code, review, and implementation.
- `raster/v1/`: original PNG archive in the complete migration package. Text governance and manifest files are already committed; large PNG binaries are added only through a direct binary Git workflow.

The WebP mirror preserves page dimensions, composition, color relationships, typography, and texture closely enough for screen implementation. It is not a replacement for token, component, SVG, typography, state, or interaction specifications.
