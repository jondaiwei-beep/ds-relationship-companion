# Color system · draft freeze

## Brand primitives

| Token | Hex | Role |
|---|---:|---|
| Bone | `#F4F1EB` | Primary light text and warm light canvas |
| Stone | `#E7E3DA` | Secondary light surface/text |
| Warm Gray | `#BAB6AC` | Muted information |
| Deep Olive | `#2F3A2E` | Authority and primary action structure |
| Dark Moss | `#1E241F` | Dark structure and elevated surfaces |
| Terracotta | `#B5533B` | Partner warmth and selected human response |

The near-black ritual canvas and secondary semantic colors remain calibration candidates until extracted and approved against the selected reference. Application code must consume semantic tokens, not these primitive values directly.

Terracotta must not become a generic warning color. It expresses partner presence and human acknowledgement; destructive use is reserved for the final confirmation threshold.
