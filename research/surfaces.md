# 界面分工：四个 tab 各管什么

2026-09-02，讨论稿。依据 synthesis.md 与后续讨论；每个 tab 的功能都能在 research/ 里找到出处。sub / Dom 看到的是同一个 tab、不同的内容。

## 1. 今天 —— 每天来的地方

| sub 看到 | Dom 看到 |
|---|---|
| 今日清单：循环项 / Dom 临时加的 / 无截止的自愿加分项 | 等我处置的：一列，每条两下（看到了 / 很好 / 算了 / 补上 / 罚） |
| 每条：勾 / 拍照 / 一句话 → 立刻"已送到，等 TA 看" | 我要记得的：Dom 自己的备忘和提醒 |
| 没做的四个出口：做不了 / 求个新时间 / 想谈谈 / 我认，晚了（附原因） | 快速加一条给今天 |
| 早/晚问安（可一天多次） | "今晚要什么？" 一键抽卡（探索的高频入口） |
| 顶部：分余额、连续天数、今天从几点算 | 顶部：sub 今天的完成概况 |

widget / 锁屏 / 提醒 都从这里出。Dom 不在时的"按条暂停"状态在这里可见。

## 2. 规矩 —— 长期的东西，有事才来

- 常设协议与规则（称呼、跪迎、禁慾、着装……），和"今天的任务"分开
- 奖励目录（Dom 自定义；sub 兑换需 Dom 点头）
- 惩罚库（由 Dom 手动触发，永不自动）
- 底线 / 安全词（= 两人比对里"不要"的那一栏）
- Dom 缺席：按条暂停"需要我在场的"
- **探索的家**：
  - 两人各答、系统比对（想要 / 可以 / 不要 / 想聊；答完才互见；只显示交集和"想聊"）
  - 灵感卡（给 Dom / 给 sub / 给两人），每张都是动词：加到今天 / 加到规矩 / 提议给对方
  - 起步包（首日挑一个，改成自己的话）

## 3. 记录 —— 回头看，晚上当面收尾

- 日历，一天一格：做了 / 没做 / 说了什么 / Dom 怎么处置的
- 两人都能在某一天上留言（求饒 / 處罰 / 一句话）
- 交付照片/文字的归档
- sub 的事后感受；Dom 的私人备注（只有自己看）
- 周 / 月回看：事实陈述，不评价
- 曲线（体重、饮水这类可量化的项）
- 分的流水（谁给的、为什么、兑换了什么）

## 4. 分 —— 余额与兑换

- 余额、可兑换的奖励、兑换请求
- Dom：给 / 扣 / 自由裁量加分（附一句为什么）
- 规则可见：哪些项给分、哪些项只有没做才扣（默认基础项不给分）
- 连续天数（只涨不跌）

（备选：若探索必须是 tab，则用探索替换分；余额挂今天顶部，流水已在记录。推荐不替换。）

## 右上角：设置

设备锁、通知（中性文案）、伴侣与角色、一天从几点开始、时区、付费（单方付费，免费不限条数）、暂停整个动态、离开、导出。

## 首日路线

设锁 → 选角色 → 邀请对方（可晚到，单人先能用）→ 挑一个起步包改成自己的话 → 当晚第一次在"记录"里对着这一天收尾。

## 横切原则（来自语料，不是哲学）

1. 系统从不替伴侣开口；所有评价、分、罚都有 `by 谁`。
2. Dom 审阅不计时；Dom 缺席不产生债。
3. 没做永远有正规出口，且落在"那一天"上。
4. 内容说 D/s 的话；语气 playful but serious。
5. 私密在门口解决（锁、中性通知），不靠阉割门后内容。
